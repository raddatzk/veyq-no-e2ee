# veyq Trademark Policy

This policy keeps the self-hostable community edition free to use while reserving veyq's brand identity.

## Reserved Marks

The veyq name, logos, icons, wordmarks, product screenshots that include branded UI, and other brand assets are reserved by the project maintainers unless a separate written permission says otherwise.

The AGPL license for the software does not grant trademark rights.

## Allowed Uses

You may use the veyq name to:

- Refer truthfully to the upstream project.
- Describe compatibility, forks or integrations.
- Link to the upstream repository or documentation.
- State that your deployment is powered by veyq.

These uses must not imply endorsement, official hosting, certification or project control by the upstream maintainers.

## Forks And Modified Versions

Forks and modified distributions should use a clearly different product name and visual identity unless they are distributed as unmodified veyq builds.

If a fork keeps the veyq name in documentation, release notes or package metadata, it must make the fork status clear to users and operators.

## Hosted Services

Do not offer a public hosted service using the veyq name, logos or confusingly similar branding without written permission.

Self-hosted private deployments may keep the default veyq branding.

## Contact

For trademark permission, commercial use or hosted-service branding, contact the project maintainers through the repository.
