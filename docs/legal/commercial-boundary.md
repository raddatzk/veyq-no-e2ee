# Commercial Boundary

veyq V1 is released as a self-hostable community edition under AGPL-3.0-only.

## Community Baseline

The community edition must remain useful without central veyq infrastructure. A self-hoster should be able to run the core Memory product with local accounts, local media storage, tenant/group spaces, uploads, journals and public sharing.

Community features must not require managed hosting, license tokens, telemetry services or hosted veyq APIs.

## Optional Commercial Layers

Future commercial work may add optional services, for example:

- Managed hosting.
- Paid support or maintenance.
- Hosted push gateways.
- Federation helpers or relay services.
- Enterprise administration features.
- Commercial licenses for organizations that cannot use AGPL terms.

Those layers must remain optional and must not remove the self-hostable V1 baseline.

## Source Availability

Public container images and source releases must point users to the corresponding source for the released version.

If a modified network deployment is offered publicly, AGPL section 13 applies to that modified version.

## Brand Boundary

Commercial services may not use the veyq name, logos or confusingly similar branding without permission. See `docs/legal/trademark-policy.md`.
